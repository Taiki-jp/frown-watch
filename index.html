値は 0〜1。無表情の基準を取ると、基準からの増分で判定します。「今の値」を見ながらしきい値を決めてください。

思いきり顰めて、どの値が動くかを見るための表。判定には今のところ browDownLeft と browDownRight の平均だけを使っています。

動作条件

  • Chrome 116 以降。小窓表示は Safari と Firefox では使えません
  • http://localhost か https で開くこと。カメラの許可が必要です
  • 判定ライブラリとモデルはこのページと一緒に配布しています。外部のサーバーからは何も読み込みません
  • 映像は端末内で処理し、記録はこのブラウザの localStorage にだけ残ります

映像が外に出ないことの確認方法

  • 開発者ツールの Network タブを開いたままカメラを開始する。最初の読み込み以外に通信が起きません
  • カメラを開始したあとに Wi-Fi を切っても、そのまま動き続けます
  • このページの CSP で、配布元以外への通信をブラウザ自身が禁止しています。ページのソースの冒頭にある meta タグで確認できます
  • ビルド工程がなく、配布しているファイルがそのまま動きます。「ページのソースを表示」で全文を読めます
  • ソースコードは GitHub の公開リポジトリ にあり、そこからそのまま配信しています
